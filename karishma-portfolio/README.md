# Karishma Pal - Portfolio

React + Vite portfolio site.

## Run it

1. Install Node.js 18 or newer from https://nodejs.org
2. In this folder run:

   npm install
   npm run dev

3. Open the address shown in the terminal (usually http://localhost:5173).

## Edit your content

All text, links, projects and skills are in `src/data.js`. Change them there and the site updates.
Your resume PDF is in `public/Karishma_Pal_Resume.pdf`. Replace it with a new file of the same name to update the download.

## Put it online

Run `npm run build`, then upload the `dist` folder to Netlify, Vercel or GitHub Pages.
